# Sample datasets

Small, citable extracts of the Black Cultural Knowledge Graph for testing,
teaching, and tool-building — so an integration can be proven against real
CTL data before working with the full slice.

| File | What it is |
|---|---|
| `entities-sample.csv` | The first 100 records of the stamped slice (by record ID), in the slice's own CSV format — see `../DATA-DICTIONARY.md`. |
| `entities-sample.jsonld` | The same 100 records as JSON-LD, each with a stable `@id` under culturetechlens.com/graph/. |

The full stamped slice — 3,488 entities and 2,162 relationships, every
record evidence-graded — is in [`../knowledge-graph/`](../knowledge-graph/).
Canonical figures live in [`../counts.json`](../counts.json) and are
verified in CI on every change.
