# Governance

**Tags:** governance, policy, packaging-standard, sponsorship, ip-licensing

Public institutional rules. Drafts never live here — a policy appears in this folder the day it is adopted, so anything found here can be relied on. This folder is the public mirror of CTL's governance binder.

## Adopted instruments (index)
| ID | Instrument | Scope in one line |
|---|---|---|
| CTL-GOV-001 | Institution standard | What makes CTL an institution rather than a feed: research depth never substitutes for governance maturity. |
| CTL-GOV-004 | Source rule | No factual claim ships without a source supporting the exact claim; UNRESOLVED is never asserted. |
| CTL-GOV-ZIP-001 | Packaging standard | One package per deliverable, unique filenames, versioned ZIPs, SHA-256 checksums, nothing silently overwritten or deleted. |
| CTL-PUB-001 | Companion publishing rule | culturetechlens.com is the authoritative record; companion channels (Blogger, social) point to it, never duplicate it. |
| CTL-PHOTO-001 | Documentary Image Integrity | Five sources, three image categories, a full per-image record (source, creator, rights, credit, verification date) before any image publishes. Supplements: PHOTO-SUP-001 (treatment/branding), PHOTO-SUP-002 (Chicago collections lanes). |
| CTL-KG-001 | Knowledge graph schema | Entity types, the 64-type relationship matrix, and validation rules for CTL-KG-001 (see `knowledge-graph/schema/`). |
| CTL Phase 0 | GitHub ruling (2026-10-19) | One flagship repository; content CC BY 4.0 / code MIT; **snapshot-only** data posture; legacy repos archived, never deleted. |

## Decision rule
Adoptions, rulings, and count changes are made by the founder and recorded with their date. Work produced for CTL — by any contributor or tool — enters through review against these instruments before it is relied on.

Canonical home: CTL governance binder (internal). This folder is the public mirror.
