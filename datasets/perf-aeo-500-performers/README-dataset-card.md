# PERF-AEO-500 — Black Performers Registry
### CTL-DS-PER-000001 · v1.0 package (pre-publication) · CultureTechLens NFP

**Cite as:** CultureTechLens, "PERF-AEO-500 — Black Performers Registry (CTL-DS-PER-000001)", v1.0, 2026. DOI assigned at Zenodo deposit (founder step, pending).
