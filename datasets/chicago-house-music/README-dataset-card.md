# Chicago House Music Knowledge Graph — Specialist Dataset, 1977–1995
### CTL-DS-MUS-000001 · v1.0 package (pre-publication) · CultureTechLens NFP

**Cite as:** CultureTechLens, "Chicago House Music Knowledge Graph — Specialist Dataset, 1977–1995 (CTL-DS-MUS-000001)", v1.0, 2026. DOI is assigned at Zenodo deposit (founder step, pending). Parent work: Black Cultural Knowledge Graph, concept DOI 10.5281/zenodo.23403147.

**What it is:** an evidence-graded dataset of Chicago house music's founding era — 18 venues, 115 artists, 16 labels, 46 recordings (45 Discogs-verified), 156 network relationships, a 368-claim evidence register (Verified 154 · Supported 116 · Provisional 50 · Disputed 28 · Unresolved 20), a 50-source bibliography, and a 49-file photo candidate manifest (**all UNVERIFIED — not cleared for use**). 818 data rows. Every claim graded; every source named; unknowns left blank, never zeroed.

**Status:** v1.0 package assembled 2026-11-16 from the v0.1 staged build (2026-11-14) under the dataset spec of the same date. Not yet published. Dataset ID and grade mapping ruled/ratified by William Maxey, 2026-11-16. License on publication: CC BY 4.0 (open core, CTL-TERMS-001).

**Known limits (printed, not hidden):** 73 of 115 artists ungraded in source · claim IDs are lane-scoped (43 rows unnumbered, 60 IDs repeat across lanes) · 170 of 380 staged network endpoints still lack display names (their entity files live in the source briefs) · venue coordinates blank by design — no map ships until address verification clears · the evidence register's near-duplicate claims in different wordings await a human review pass (exact dedupe found zero).
